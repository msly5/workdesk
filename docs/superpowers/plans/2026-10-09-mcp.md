# 紧凑顶部与本地 MCP

用户已授权实现。沿用本机服务和现有数据，不重置示例或用户资料。

1. 顶部改成紧凑标题行、下一步行；目标可展开；保留编辑、状态、视图入口。
2. 官方 MCP SDK 提供本机 Streamable HTTP `/mcp`；stdio 入口桥接同一服务。
3. 提供任务查询/新建/更新/归档，卡片读写、待办项、连线和附件工具；可选版本约束；只访问工作台数据。
4. 所有写入经过同一事务队列。网页带基准快照保存；不同字段三方合并，同字段冲突保留两份并提示。网页空闲时自动刷新。
5. 提供连接说明和通用客户端配置；不自动修改用户智能体配置。
6. SDK 客户端端到端验证、并发与冲突验证，浏览器检查高度、编辑和实时同步。
