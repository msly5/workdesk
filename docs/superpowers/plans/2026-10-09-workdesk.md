# 本地工作台实现计划

**目标：** 交付可启动、可日常使用的本地任务画布首版。

**架构：** 无构建依赖的浏览器模块与 Node.js 标准库本地服务。存储、示例数据、HTTP 路由、画布交互、编辑界面各自分离。

## 文件职责

- server.mjs：本地服务、静态文件、上传下载与备份接口。
- storage.mjs：状态校验、版本控制、原子保存、Markdown 与附件存储。
- seed.mjs：示例任务与卡片。
- public/index.html、styles.css：应用结构与响应式布局。
- public/app.js：任务管理、卡片编辑、自动保存及文件处理。
- public/canvas.js：拖拽、缩放、平移、连线。
- public/markdown.js：安全 Markdown 预览。
- tests/storage.test.mjs、tests/server.test.mjs：持久化与 HTTP 验收。
- start.cmd、README.md：双击启动与使用说明。
