# 本地文件夹卡片实现计划

**目标：** 用户添加本地文件夹路径，点击卡片按钮打开对应文件夹。

**方案：** 复用 `link` 卡片，以 `localFolder: true` 和 `folderPath` 保存文件夹引用。底部增加“文件夹”入口，链接编辑器可切换网页链接和本地文件夹。标题、路径与备注自动保存，画布和列表使用相同卡片。已有不含 `folderPath` 的本机数据卡片继续打开工作台数据目录。

**打开流程：** 网页先保存当前修改，再提交任务和卡片 ID。服务端从保存的卡片读取路径，校验 Windows 本机绝对路径及目录存在性，最后使用独立参数启动可见的 Explorer。接受中文、空格、正反斜杠以及 Windows“复制为路径”产生的外层双引号。空白、相对路径、网络和设备路径、协议地址及普通文件均返回具体错误，不执行系统命令。

**智能体：** `create_card` / `update_card` 添加 `folder_path` 字段，仅适用于 `link`，与 `url` 互斥；只保存引用，不增加自动打开或读取文件夹内容的 MCP 工具。

**文件职责：** `server.mjs` 负责目录校验和打开；`storage.mjs` 校验新增字段；`workdesk-service.mjs` 提供 MCP 字段；`public/app.js`、`public/index.html`、`public/styles.css` 提供添加、编辑、展示及点击行为；README 说明使用方法。
