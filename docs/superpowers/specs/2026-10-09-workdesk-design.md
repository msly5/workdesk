# 本地工作台

首版采用用户已同意的混合画布方案，手动推进任务。应用仅监听 127.0.0.1，所有数据存放在项目 data 目录。无需账号、云端或第三方在线资源。

## 交互

左侧是可搜索的任务列表和状态筛选；中间是每个任务独立的无限画布，可拖动卡片、平移、缩放、适应内容与连线；右侧抽屉编辑卡片。画布顶部显示目标、下一步和任务状态。提供列表视图，展示同一任务中的卡片。

支持待办、Markdown、便签、链接、图片与附件。支持文件拖入和粘贴剪贴板图片；Markdown 编辑与预览；附件下载；步骤连线与删除；任务新增、重命名、完成、归档与恢复；卡片删除提供撤销。空任务显示操作引导。

浅灰点阵画布、白色侧栏、墨色文字和蓝紫色操作色，卡片按类型标识颜色。内置明确标注的示例任务，方便理解操作。所有按钮必须具有可用行为。

## 数据与可靠性

Node.js 标准库 HTTP 服务提供静态界面、工作区读写与文件上传。state.json 原子写入，保留上一版备份；Markdown 卡片同步写入各任务的 docs 文件夹；附件按任务归档。前端串行自动保存，错误时显示失败与重试。版本号防止多窗口覆盖。上传上限 25 MB，不执行附件内容。备份导出包含附件。

## 验收

验证任务之间的画布隔离、编辑及位置刷新后保留、文件字节上传下载一致、Markdown 保存落盘、非法路径拒绝、冲突版本不覆盖。浏览器检查创建任务、卡片编辑、连线、待办勾选、缩放和布局。
